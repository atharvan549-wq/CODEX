# Security notes

This repository is an educational wallet security demonstration.

- Never enter or transmit a recovery phrase or private key into this app.
- The app does not include a transfer, approval, sweeping, or asset-draining function.
- All simulated incident/return steps are local frontend state only.
- Use a dedicated test wallet and Sepolia test ETH for demonstrations.
- Review wallet prompts before approving any action in other dApps.
- Report suspected vulnerabilities through a private channel to the repository maintainer; do not publish exploit details before remediation.
